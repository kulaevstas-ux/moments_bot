# 🎨 Telegram Bot — AI Coloring Book Generator

Telegram-бот для создания чёрно-белых контурных раскрасок из фотографий пользователя с использованием ИИ через ProxyAPI.

## 📋 Описание

Бот позволяет пользователям:
- Загружать свои фотографии (минимум 4)
- Выбирать стиль раскраски (Дисней, Аниме, Симпсоны, Комикс, Детский, Реализм)
- Оплачивать заказ (заглушка)
- Получать готовый PDF-файл с раскрасками

## 🚀 Установка

1. Клонируйте репозиторий или скачайте файлы
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта:
   - Скопируйте `.env.example` в `.env`
   - Заполните необходимые ключи:
     - `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather)
     - `PROXY_API_KEY` — получите на [proxyapi.ru](https://proxyapi.ru)

```bash
cp .env.example .env
# Затем отредактируйте .env и добавьте свои ключи
```

4. Создайте папки для ассетов (опционально):
   - `bot/assets/start_placeholder.jpg` — фото для приветственного сообщения
   - `bot/assets/styles_placeholder.jpg` — фото для выбора стиля

## 🏃 Запуск

### Обычный запуск

```bash
python3 run.py
```

или

```bash
python3 -m bot.main
```

### Управление ботом

**Остановить все экземпляры бота:**
```bash
./stop_bot.sh
```

или вручную:
```bash
pkill -9 -f "python.*run.py"
```

**Перезапустить бота:**
```bash
./restart_bot.sh
```

**Проверить, запущен ли бот:**
```bash
ps aux | grep "python.*run.py" | grep -v grep
```

## ⚙️ Конфигурация

### Переменные окружения (.env)

Все API ключи хранятся в файле `.env`:
- `BOT_TOKEN` — токен Telegram-бота (получите у @BotFather)
- `PROXY_API_KEY` — ключ API ProxyAPI (получите на proxyapi.ru)

### Другие настройки

Остальные настройки находятся в `bot/config.py`:
- `PRICE_PER_PHOTO` — стоимость за одно фото (28 ₽)
- `MIN_PHOTOS` — минимальное количество фото (4)

## 🔧 API

Бот использует ProxyAPI через OpenAI SDK для генерации изображений:
- Модель: `gpt-image-1-mini`
- Размер: `1024x1536`
- Качество: `high`
- Метод: `images.edit` с параметрами через `extra_body`

## 📝 Примечания

- Оплата реализована как заглушка (90% успешных платежей)
- Фото сохраняются локально в `bot/data/photos/`
- Данные пользователей хранятся в JSON-файле
- PDF создаётся с помощью библиотеки reportlab

## 🐛 Устранение неполадок

Если бот не запускается:
1. Проверьте, что установлен токен бота
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к папкам `bot/data/` и `bot/assets/`
